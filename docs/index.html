Guest transfer

Privacy Policy

Waitwhile to PetPoint Chrome Extension

Effective date: July 15, 2026

Waitwhile to PetPoint helps users transfer a user-selected guest's information from Waitwhile to PetPoint. The extension processes this information locally in the user's browser.

Information processed

When initiated by the user, the extension may process information displayed in the currently opened Waitwhile guest record:

  • Name
  • Telephone number
  • Email address
  • Address
  • Waitwhile record identifier
  • Notes

How information is used

The information is used only to search for a corresponding person in PetPoint, help the user identify possible matches, and prefill a new-person form when the user requests it. The extension does not automatically submit or save PetPoint records.

Local storage

Selected guest information is temporarily stored using Chrome's local extension storage so it remains available when the user moves from Waitwhile to PetPoint. The extension developer does not receive or remotely store this information. The user can remove it with the extension's Clear guest button or by uninstalling the extension.

Data sharing

The extension does not sell, rent, or share user information with advertisers, data brokers, or unrelated third parties. Information is transferred only between the Waitwhile and PetPoint pages opened by the user as necessary to provide the extension's stated functionality.

Remote servers, analytics, and advertising

The extension does not transmit guest information to developer-operated servers. It does not use analytics services, advertising services, tracking technologies, or remotely hosted executable code.

Permissions

The extension requests access only to store the selected guest locally, read the currently opened Waitwhile guest details, and search or prefill fields on the currently opened PetPoint page. These capabilities are used only in support of user-requested actions.

Data security

All executable extension code is included in the installed extension package. Guest information is processed locally within the user's browser.

Changes to this policy

This policy may be updated when the extension's functionality or data practices change. Updates will be posted on this page with a revised effective date.

Contact

Questions about this privacy policy may be submitted through the support contact shown on the extension's Chrome Web Store listing.

Waitwhile to PetPoint is an independent integration. References to Waitwhile and PetPoint describe compatibility and do not imply endorsement.
